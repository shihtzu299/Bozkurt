# Bozkurt

Bozkurt is a premium memecoin landing page built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

It is designed as a cinematic crypto launch website with:
- animated hero section
- countdown timer
- token / contract section
- social links
- glassmorphism UI
- responsive design
- Vercel-ready deployment

---

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

---

## Features

- Premium animated landing page
- Interactive cursor glow
- Hero parallax effects
- Intro/loading animation
- Roadmap section
- Lore / manifesto section
- Token and contract display
- Copy-to-clipboard contract button
- Placeholder Pump.fun / Dexscreener / Birdeye links
- Responsive mobile layout
- Vercel deployment support

## Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/bozkurt.git
cd bozkurt
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

---

## Deployment

This project is ready to deploy on **Vercel**.

Recommended settings:

* Framework Preset: `Vite`
* Root Directory: `./`
* Build Command: `npm run build`
* Output Directory: `dist`
